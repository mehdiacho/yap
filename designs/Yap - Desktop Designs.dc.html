09
Desktop layout spec — for AI Studio handoff
Desktop shares all foundation tokens with the phone kit (color, type, radius, motion — see the Android Ratio Spec). This section only covers the window-scale rules that differ: resizable panes instead of a single stacked column.
Window & responsive behavior
Baseline / min / max
1280×800 design baseline · 960×600 minimum · scales to 1920×1080 maximized.
Titlebar
44px fixed. Custom chrome: logo+wordmark left, centered Record pill (Ctrl+R), window controls right. On macOS, traffic-lights replace right-side controls and the logo shifts right of them.
Nav rail
78px fixed width, always visible (replaces the phone's bottom nav). 64px-wide active pill, 14px radius. Avatar pinned to rail bottom. Below 1100px it stays icon+label; it never collapses to a hamburger.
Library list column
400px at baseline; user-resizable 320–520px (drag divider). Below 960px total width the detail pane collapses and selecting a note pushes it over the list (mobile-style back button appears).
Detail / capture pane
Flexible (fills remaining width). Reading content capped at ~640px measure and left-aligned so text doesn't sprawl on wide monitors.
Row / control heights
List rows auto-height (~76px) · settings rows 44px icon target · search field 44px · docked player 44px play button. All fixed dp — do not scale with window.
Hover / focus (new vs mobile)
Every row/button gets a hover state: +4% on-surface overlay (Surface Container High). Keyboard focus: 2px Primary ring, 2px offset. List selection = Primary Container fill (distinct from hover).
Dialogs vs sheets
Bottom sheets become centered modal dialogs (28px radius, 480px width, scrim rgba(20,18,30,.45)). Actions bottom-right, primary rightmost.
Tray flyout
340px wide, anchored to tray icon, 16px radius. Quick-record button + up to 3 recent notes + Open/Quit footer.
Tray icon states
Idle (mark) · Recording (coral + pulsing dot) · Polishing (spinning glyph) · Pending sync (amber count badge).
Global mini-overlay
Always-on-top, ~360px, draggable, frameless. Coral record button + timer + mini waveform + stop. Esc discards, Enter stops & saves.
Keyboard shortcuts
Ctrl+R — record (in-app) Ctrl+Shift+R — global capture Ctrl+K — search Space — play/pause · pause rec B — bookmark while recording Enter — stop & save · Esc — discard ↑/↓ — move through list
