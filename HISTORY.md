# History

Repositories folded into this one. Each keeps its full commit history under
`history/<name>/`. To read those commits, find the "Fold <name>" commit and run
`git log <that commit>^2`. The original repositories were deleted on 2026-11-14; everything they held is in this one.

- **yap-desktop** (2026-07-28 to 2026-07-30) — Desktop companion for Yap — live library and sync over the shared Firebase backend.: `history/yap-desktop/`. The original repository `yap-desktop` was deleted on 2026-11-14 once its history was here.
- **transcriber** (2026-06-08 to 2026-10-18) — Transcriber App: `history/transcriber/`. The original repository `transcriber` was deleted on 2026-11-14 once its history was here.
