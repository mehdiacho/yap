# History

Repositories folded into this one. Each keeps its full commit history under
`history/<name>/`. To read those commits, find the "Fold <name>" commit and run
`git log <that commit>^2`. The original repository is archived on GitHub, never deleted.

- **yap-desktop** (2026-07-28 to 2026-07-30) — Desktop companion for Yap — live library and sync over the shared Firebase backend.: `history/yap-desktop/`, original at https://github.com/mehdiacho/yap-desktop (archived).
- **transcriber** (2026-06-08 to 2026-10-18) — Transcriber App: `history/transcriber/`, original at https://github.com/mehdiacho/transcriber (archived).
